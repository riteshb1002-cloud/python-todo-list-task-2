# Task 2 - To-Do List Application

## Description

This project is a console-based To-Do List Application developed using Python.

The application allows users to:

- Add tasks
- View tasks
- Remove tasks
- Store tasks permanently in a text file

## Technologies Used

- Python
- VS Code

## Files

- `todo.py` - Main Python program
- `tasks.txt` - Stores the tasks
- `README.md` - Project documentation

## How to Run

Open the terminal and run:

```bash
python todo.py
